# Сборка десктопной программы «АРМ Дежурного ВГСЧ»

Программа — это тот же интерфейс АРМ, упакованный в обычное
Windows-приложение `VGSCH-ARM.exe`. Интернет для работы не нужен:
все файлы лежат рядом с программой, данные хранятся на самом компьютере.

## Что нужно установить на компьютере сборщика

| Нужно | Где взять |
|---|---|
| Node.js LTS | https://nodejs.org |
| .NET 8 SDK (именно SDK, не Runtime) | https://dotnet.microsoft.com/download/dotnet/8.0 |
| Inno Setup 6 — только для установщика | https://jrsoftware.org/isdl.php |

## Как собрать

Скопируйте **весь проект** на компьютер с Windows и запустите:

```
desktop\csharp\build.bat
```

Файл можно просто запустить двойным кликом.

### Режимы сборки

| Команда | Что делает |
|---|---|
| `build.bat` | Собирает `VGSCH-ARM.exe` в `desktop\csharp\dist` |
| `build.bat noobf` | То же, но без защиты кода (если нет доступа к nuget.org) |
| `build.bat install` | Собирает и сразу ставит в `C:\VGSCH-ARM` + ярлыки |
| `build.bat installer` | Собирает установщик `VGSCH-ARM-Setup-1.0.0.exe` — один файл для раздачи |
| `build.bat notest` | Пропустить проверку запуска (см. ниже) |

### Проверка запуска

После сборки скрипт сам запускает готовую программу, ждёт, пока
откроется окно, и проверяет, что она не упала. Проверка не прошла —
сборка останавливается, установщик не создаётся: лучше поймать
поломку здесь, чем раздать дежурным нерабочий файл.

Если проверка падает, скрипт подсказывает, что смотреть: обычно это
отсутствующий компонент WebView2 или не скопировавшиеся файлы интерфейса.
Собрать в обход проверки: `build.bat notest`.

### Версия программы

Меняется вручную в файле `desktop\APP_VERSION` (например `1.0.1`).
Автоувеличения нет — версию ставит сборщик.

## Что получается на выходе

```
desktop\csharp\dist\
    VGSCH-ARM.exe      программа (один файл, .NET внутри)
    vgsch.ico          иконка
    app_version.txt    версия
    web\               интерфейс АРМ
```

Установщик: `desktop\csharp\installer-out\VGSCH-ARM-Setup-<версия>.exe`
— ставит программу в `C:\VGSCH-ARM`, создаёт ярлыки на рабочем столе
и в меню «Пуск», при необходимости доставляет компонент WebView2.

## Горячие клавиши в программе

| Клавиша | Действие |
|---|---|
| `F5` | Перезагрузить интерфейс |
| `F9` | Проверить обновление вручную |
| `F11` | Полноэкранный режим |

Табло и печать путёвки открываются в отдельном окне программы.

## Автообновление

Программа при запуске сама спрашивает сервер, нет ли версии новее,
и предлагает дежурному обновиться. Нет интернета на рабочем месте —
проверка тихо пропускается, программа работает как обычно.

**Как выпустить обновление:**

1. Поднимите версию в `desktop\APP_VERSION` (например `1.0.1`)
2. Соберите установщик: `desktop\csharp\build.bat installer`
3. Откройте АРМ в браузере → раздел **«Сборка»**
4. Введите код администратора, перетащите `VGSCH-ARM-Setup-1.0.1.exe`, укажите что нового
5. Нажмите «Опубликовать обновление»

Дежурные получат предложение обновиться при следующем запуске программы.

**Раздать программу новым дежурным:** отправьте им ссылку вида
`https://ваш-адрес/download` — там всегда лежит последняя версия
с короткой инструкцией по установке. Ссылку можно скопировать
в разделе «Сборка».

Галочка **«Обязательное обновление»** — программа не даст работать на
старой версии, только установить новую или выйти.

Адрес сервиса обновлений хранится в `desktop\update_url.txt`. Удалите
этот файл, если нужно собрать версию вообще без проверки обновлений.
